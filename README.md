---

## 📖 Sobre o Projeto

**Cancunf Flash** é um **script em Python** criado para facilitar a instalação de **Custom ROMs** nos dispositivos **Moto G54 / G64**.

Ele automatiza tarefas que normalmente seriam manuais:

* ⚡ Configuração automática do sistema e instalação da **Platform-Tools**
* 📦 Flash do **Initial ZIP**
* 📦 Flash do **ZIP da ROM customizada**
* 🛡️ Flash do **KSU / KSU Next**
* 📚 Guias e explicações sobre modificações seguras do aparelho

---

## 🛠️ Requisitos

* **Python 3.x**
* **Cabo USB de boa qualidade**
* **Backup completo dos dados** (o processo apaga tudo!)
* Compatível com **Windows** e **Linux**
* **Termux:** não oficialmente suportado (pode exigir adaptações)

---

## ⚡ Como Usar

1. Entre na pasta `setup`
2. Execute o script do seu sistema operacional:

   * **Windows:** `setup-windows.bat`
   * **Linux:** `setup-linux.sh`
3. Rode o script principal:

   ```bash
   python cancunfFlash.py
   ```

> 🔹 Certifique-se de que o **bootloader está desbloqueado** antes de iniciar.
